# ProyectoAlex

## 1. Descripción del proyecto

Proyecto desarrollado en Python que contiene un backend encargado de ejecutar la lógica principal del sistema y trabajar con una base de datos vectorial.

El proyecto incluye módulos de procesamiento, almacenamiento de información y un programa principal para iniciar su ejecución.

## 2. Objetivo

Organizar e implementar los componentes del backend para facilitar su ejecución, mantenimiento y futura integración con el frontend del sistema.

## 3. Tecnologías utilizadas

- Python
- Base de datos vectorial
- Bibliotecas de Python utilizadas por el proyecto

## 4. Estructura del proyecto

```text
ProyectoAlex/
├── Backend/
│   ├── main.py
│   ├── entrenar_modelo.py
│   ├── logica/
│   └── base de datos/
│       └── vector_db/
├── Frontend/
├── FullStack/
├── README.md
└── .gitignore
```

## 5. Requisitos

- Sistema operativo compatible con la aplicación.
- Python, si se ejecuta desde el código fuente.
- Dependencias especificadas en `requirements.txt`.
- Archivos del modelo y datos necesarios para el funcionamiento del sistema.

## 6. Instalación y ejecución desde el código fuente

1. Clonar el repositorio:

   ```bash
   git clone URL_DEL_REPOSITORIO
   ```

2. Entrar en la carpeta del backend:

   ```bash
   cd Backend
   ```

3. Instalar las dependencias:

   ```bash
   python -m pip install -r requirements.txt
   ```

4. Ejecutar el programa principal:

   ```bash
   python main.py
   ```

## 7. Ejecución del programa

El proyecto contará con un ejecutable para Windows generado a partir del programa principal.

Para utilizarlo, se deberá ejecutar el archivo correspondiente dentro de la carpeta de distribución y conservar los archivos auxiliares que requiera la aplicación.

La ejecución debe realizarse siguiendo las instrucciones y requisitos documentados para la versión entregada.

## 8. Entrenamiento del modelo

El archivo `entrenar_modelo.py` contiene el proceso de entrenamiento del modelo.

Su ejecución dependerá de las bibliotecas, los datos de entrada y los archivos de configuración requeridos por el proyecto.

## 9. Base de datos vectorial

La carpeta `base de datos/vector_db/` contiene los recursos asociados con el almacenamiento vectorial del proyecto, cuando corresponda.

Estos archivos deben conservarse o generarse mediante el procedimiento de inicialización definido por la aplicación.
